================================================================================
  param8 Firmware Changelog
================================================================================

v1.1.0 — 2026-11-20
--------------------
 
    DAW actions:

    - Global mode is now customizable from the editor. Actions cover global functions (transport, Undo/Redo etc),
    Session or Arrangement functions, per track /device functions, and Preset navigation functions.

    - DAW actions can be assigned to any control in a User preset, without
      leaving that preset.

    Slew / settings :

    - Slew: smooth transition times for Latch and Revert, configurable in the
      Settings page. Available in time (ms) or beat-synced mode.

    - Settings (brightness, screen saver, slew) are accessible directly on the
      device with a double press on Shift.

    Display :

    - Quantized parameters: controls mapped to stepped or on/off parameters
      now display as rectangular blocks in the Dynamic layout.

    - Labels are available on all pages and can be customized.

    Editor :

    - Editor: changes are no longer sent automatically — press Send
      (or Cmd/Ctrl+U) to upload to param8.

    - Controls can be swapped

    Various :

    - PB speed has been improved

    - Trigger press mode: a third button mode alongside Toggle and Momentary.
      Sends the maximum value on press only, nothing on release.
    
    - In Device Mode, A/B has been replaced by Capture to make way for Live 13


--------------------------------------------------------------------------------

v1.0.2 — 2026-10-17
--------------------

  Preset page
    - Selecting a preset now immediately deselects the previous one in a single
      display flush, so there is no visual overlap between the old and new active
      preset LEDs.
    - Further preset selection is locked until Shift is released
      (presetJustSelected flag), preventing accidental double-selection on a
      quick press.

  Utility device
    - The Output parameter is now correctly labelled "Gain", matching the name
      exposed by the Live API.

  Dimmed parameters
    - Parameters shown in a dimmed state now render the fader fill (grey) and
      needle in the compact layout, keeping the display consistent with active
      parameters.

  Bug fixes
    - Fixed: the active preset LED was not deselected immediately after a
      shift long-press selection — it stayed lit until the next showDisplay()
      cycle.
    - Fixed: releasing a button after a shift long-press action was triggering
      the button's normal MIDI message. The button is now silenced when
      Shift was held.
    - Fixed: while in preset selection mode (Shift held) coming from the Global
      preset, Live's real-time Position updates were overwriting the preset page
      display. Parameter title updates from Live are now ignored during preset
      selection.
    - Fixed: control names set in the editor were lost after disconnecting or
      rebooting the device. Names are now persisted to flash and restored on
      startup.
